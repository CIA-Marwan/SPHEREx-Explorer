# Challenge solution and limitations

The [Planet X and SPHEREx challenge](https://www.spaceappschallenge.org/2026/challenges/planet-x-and-spherex/) asks for a public coordinate-entered sequence of SPHEREx images to help people look for moving objects.

The current application provides coordinate-based archive search, real-image previews and one precomputed, wavelength-screened two-date visual comparison. Its side-by-side, divider and blink controls make that example easier to inspect. This is a partial response: it does **not** create screened, aligned multi-epoch sequences for arbitrary coordinates and does not establish detections. The interface makes that limitation explicit.

Earlier work appears to predate the normal event start; consult the Local Lead before representing the project as eligible. Do not claim a Planet X discovery.
