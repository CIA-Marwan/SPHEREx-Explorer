# NASA Data — ready-to-paste

- NASA/IPAC Infrared Science Archive SPHEREx: https://irsa.ipac.caltech.edu/Missions/spherex.html — SIA2 records and DR1/QR3 Level 2 FITS cutouts used for real observation search and previews. This resource is listed on the challenge Resources tab.
- DR1 spectral image data release: https://www.ipac.caltech.edu/doi/10.26131/IRSA678 — reference for DR1 Level 2 spectral image products.
- SPHEREx data access guide: https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-access/ — source for archive search and cutout access.
- DR1 detector 3 spectral calibration: https://nasa-irsa-spherex.s3.us-east-1.amazonaws.com/dr1/spectral_wcs/cal-swcs-v5-2026-191/3/spectral_wcs_D3_spx_cal-swcs-v5-2026-191.fits — CWAVE/CBAND calibration used to screen the saved comparison.
- SPHEREx Explanatory Supplement: https://irsa.ipac.caltech.edu/data/SPHEREx/docs/SPHEREx_Expsupp.pdf — FITS extensions and flag interpretation.
