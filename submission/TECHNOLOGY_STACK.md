# Technology stack

React, TypeScript, Vite, React Router, TanStack React Query, Zustand, OpenSeadragon, Recharts and Lucide provide the frontend. The backend uses Python, FastAPI, Uvicorn, Astropy, NumPy and Pillow. Offline pair preparation additionally uses Reproject. Vitest, Testing Library and pytest run the existing tests. The production frontend is served by FastAPI in the same-origin deployment described in the README.
